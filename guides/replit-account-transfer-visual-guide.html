Move the Built Box site to another Replit account

Use Replit’s share-and-fork process to make a copy. Then set up the copy’s private settings, test it, and move the domain only after everything works.

Important: This copies the project; it does not move or cancel a Replit subscription. Keep the original project and live site until the new copy is tested.

Before you call the move complete

☐ Website and API both run

The site needs its API for contact and formal quote emails.

☐ Private settings are re-added

Enter secret values only in Replit Secrets, never in source code or messages.

☐ Test quote email arrived

Use a clearly marked test request and confirm the destination inbox receives it.

☐ Domain points to the new deployment

Make the DNS change only after the copied site is ready. Keep the original until the switch is confirmed.

Do not delete the original yet. Forking creates a separate copy. Leave the original deployment available until the destination copy, email flow, and domain are all verified.
