---
name: Container color photography
description: Visual standard for realistic multi-color container catalog galleries.
---

Color variants of the same container model should use distinct, natural camera viewpoints rather than repeating an identical composition with only the paint color changed. Never mirror finished images because markings and text would appear backward.

**Why:** Identical backgrounds, framing, and geometry across every color make the catalog images look artificially generated.

**How to apply:** Keep the verified source-color gallery untouched. Create modest left-front, right-front, lower, or wider camera variations for modified colors, preserve the exact door state and hardware, and visually review every gallery before publishing.
