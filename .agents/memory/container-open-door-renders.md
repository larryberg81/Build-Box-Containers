---
name: Container open-door renders
description: Reliable workflow for creating catalog images with both cargo doors fully open.
---

Create the wide-open geometry from a straight-on closed-door source before producing color variants. Require both panels to sit outside the doorway against the side walls, and visually inspect the result before recoloring.

**Why:** Editing an already-open but inward-angled image tends to preserve the incorrect door geometry even when the prompt asks for a wider opening. A clean front view gives the image model a clearer transformation.

**How to apply:** First create and approve one neutral-color geometry master. If one panel remains angled, refine that panel from the improved image. Only after the opening is unobstructed should the master be recolored for the catalog.
